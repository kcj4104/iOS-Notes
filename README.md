# iOS Notes Webapp Prototype (v1)

A complete v1 prototype of iOS Notes built as a browser app.

## Features
- iOS-inspired split-pane layout (notes list + editor)
- Create, edit, delete notes
- Pin/unpin notes
- Search notes by title/body
- Local persistence via `localStorage`
- Seeded starter notes

## Run locally
```bash
npm test
npm run dev
# open http://localhost:4173
```
